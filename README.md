# JMEF Plugin for OJS 3.5

Journal Metadata Exchange Format (JMEF) export plugin for Open Journal Systems 3.5.

## Features

* Diamond OA metadata export
* DOAJ metadata export
* DOI metadata export
* CC license export
* OECD classification export
* Multilingual journal titles
* DDH-compatible XML endpoint

## Tested with

* OJS 3.5.0-4
* PHP 8.4
